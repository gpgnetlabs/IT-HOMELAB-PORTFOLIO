## Challenges Encountered

### Mistake

While attempting to create a text file, I accidentally created the wrong file because I confused the file name with the text that should be written into the file.

### Troubleshooting

Instead of deleting files immediately, I used:

```cmd
dir
```

to inspect the directory.

I learned that:

- `dir` displays files and folders.
- The number before the filename is the file size in bytes.
- `type` displays the contents of a text file.

---

## Key Takeaways

- File extensions matter.
- Hidden folders can contain important application data.
- Command Prompt navigation is much faster once the commands are learned.
- Reading command output carefully is an important troubleshooting skill.
