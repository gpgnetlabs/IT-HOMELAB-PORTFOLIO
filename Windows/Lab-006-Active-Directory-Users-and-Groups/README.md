# Lab 006 - Active Directory Users and Groups

## Objective

Create and organize an Active Directory environment by building Organizational Units (OUs), Security Groups, and User Accounts using Windows Server 2022.

---

## Skills Demonstrated

- Active Directory Domain Services (AD DS)
- Organizational Unit (OU) management
- Security Group creation
- User account creation
- User organization
- Windows Server administration
- Identity and Access Management (IAM)

---

## Environment

- VMware Workstation
- Windows Server 2022 Standard Evaluation
- Active Directory Domain Services
- Domain: gpg.local
- Domain Controller: GPG-DC01

---

## Business Scenario

A new company, **GPG Industries**, is deploying its first Active Directory environment. As the IT Administrator, I was responsible for creating the organizational structure, departmental security groups, and employee user accounts.
