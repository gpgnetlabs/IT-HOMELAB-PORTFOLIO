# Jeremy's IT Lab — CCNA Packet Tracer Labs

Practical networking exercises completed in Cisco Packet Tracer while studying for the Cisco CCNA (200-301) certification.

Each lab includes its objective, a description of the topology, implementation notes, observed results, and key networking concepts. Configuration commands and troubleshooting evidence will be added where relevant.

## Documentation Standards

- Describe only configurations and verification results demonstrated by the completed lab.
- Include topology screenshots, Packet Tracer project files, and command output when available.
- Clearly distinguish physical/logical connectivity from successful network communication.
- Note errors, their root causes, and the steps used to resolve them in future troubleshooting exercises.
